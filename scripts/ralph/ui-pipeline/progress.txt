# UI Pipeline Progress Log
Started: 2026-01-13

## Codebase Patterns

### AICaddyPro Design System
- Dark theme primary: Golf green gradient backgrounds
- Spacing scale: 4, 8, 12, 16, 24, 32, 48
- Typography: System fonts with specific weights
- Cards: GlassCard for elevated content, BoldCard for emphasis
- Touch targets: Minimum 44x44 points

### Key Files Reference
- Design tokens: `src/theme/tokens.ts`
- Typography: `src/theme/typography.ts`
- Gradients: `src/theme/gradients.ts`
- Animations: `src/theme/animations.ts`

### Typecheck Command
```bash
npx tsc --noEmit
```

### Component Structure
- Screens: `src/features/*/screen.tsx` or `src/features/redesign/screens/*.tsx`
- Core UI: `src/core/components/ui/*.tsx`
- Feature components: `src/features/*/components/*.tsx`

### React Native Patterns
- Use StyleSheet.create() not inline styles
- Prefer useCallback/useMemo for performance
- Avoid anonymous functions in render
- Use accessibilityLabel for all interactive elements

### Golf App Specifics
- Outdoor readability: High contrast required
- One-handed operation: Bottom-focused interactions
- Glanceable info: Large numbers, minimal text
- Weather context: Adapt to conditions display

### Iteration - 2026-01-13 (UI-002 Phase 2)
**Component:** UI-002 (Setup Screen)
**Phase:** gpt-cross-review
**Status:** COMPLETE

**GPT Validation Results:**
- Switches missing accessibilityLabel: CONFIRMED P0
- Club action icons 36x36: CONFIRMED P1
- Premium card broken affordance: CONFIRMED P1
- ClubRow missing accessibilityRole: Valid, P2/P1

**Over-Prioritized (GPT suggests drop to P2):**
- Theme/Unit radio "missing accessibilityLabel" - visible text usually becomes label

**NEW Blind Spots Found by GPT:**
1. Missing `accessibilityRole="radiogroup"` on Theme/Unit containers
2. Switch rows not fully tappable (only toggle, not row label)
3. Missing header structure (`accessibilityRole="header"` on title/sections)
4. Small text (12-13px) risky for outdoor/sunlight - need 14-16px
5. Premium card needs disabled state if non-functional
6. Missing hitSlop on icon-only actions

**Golf-Specific Insights:**
- Touch targets 48dp+ ideal for gloves
- Row-level tap targets for toggles
- Typography scale increase for sunlight readability
- One-hand operation: align primary actions to right side
- No fake CTAs on-course

**Output:** `reviews/UI-002-gpt-cross-review.md`
