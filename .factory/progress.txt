# Droid Factory Progress Log

## Codebase Patterns

### Project Structure
- React Native + Expo SDK 54+
- Expo Router for navigation (file-based)
- NativeWind v4 for styling (Tailwind)
- Zustand for state management
- RevenueCat for subscriptions

### Key Directories
- `src/features/` - Feature modules (play, settings, etc.)
- `src/core/` - Shared components, hooks, models
- `src/providers/` - Context providers
- `src/theme/` - Design tokens and themes

### Design Tokens
- Colors: See `src/theme/tokens.ts`
- Spacing: 4/8/12/16/24/32/48 (8pt grid)
- Touch targets: 48x48dp minimum

### Common Gotchas
- Use `@/` import alias, not relative paths
- FlashList for lists >20 items
- All interactive elements need accessibilityLabel
- Test on both iOS and Android
