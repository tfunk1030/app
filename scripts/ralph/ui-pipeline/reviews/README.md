# Reviews Directory

This directory contains all review outputs from the UI pipeline.

## File Naming Convention

```
[COMPONENT_ID]-[PHASE].md
```

Examples:
- `UI-001-rams-initial.md` - RAMS initial review of PlayScreen
- `UI-001-gpt-cross-review.md` - GPT cross-review
- `UI-001-synthesis.md` - Synthesized consensus
- `UI-001-plan.md` - Implementation plan
- `UI-001-changes.md` - Change log
- `UI-001-post-review.md` - Post-implementation review
- `UI-001-gpt-verify.md` - GPT verification

## Component IDs

| ID | Component |
|----|-----------|
| UI-001 | PlayScreen |
| UI-002 | SetupScreen |

## Usage

These files are generated automatically by the pipeline.
Do not edit manually unless debugging.
