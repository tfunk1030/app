### PYYW Protocol Value

### Learnings
- Always check BOTH token files (tokens.ts AND redesign/tokens.ts)
- Comments like "// spacing-ok" or "// Creates the gradient border effect" indicate intentional overrides
- Dual-export pattern is standard React practice, not dead code
- Never trust code for URLs - always curl to verify
