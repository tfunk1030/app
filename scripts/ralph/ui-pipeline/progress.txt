# UI Pipeline Progress Log
Started: 2026-01-13

## Codebase Patterns

### AICaddyPro Design System
- Dark theme primary: Golf green gradient backgrounds
- Spacing scale: 4, 8, 12, 16, 24, 32, 48
- Typography: System fonts with specific weights
- Cards: GlassCard for elevated content, BoldCard for emphasis
- Touch targets: Minimum 44x44 points

### Key Files Reference
- Design tokens: `src/theme/tokens.ts`
- Typography: `src/theme/typography.ts`
- Gradients: `src/theme/gradients.ts`
- Animations: `src/theme/animations.ts`

### Typecheck Command
```bash
npx tsc --noEmit
```

### Component Structure
- Screens: `src/features/*/screen.tsx` or `src/features/redesign/screens/*.tsx`
- Core UI: `src/core/components/ui/*.tsx`
- Feature components: `src/features/*/components/*.tsx`

### React Native Patterns
- Use StyleSheet.create() not inline styles
- Prefer useCallback/useMemo for performance
- Avoid anonymous functions in render
- Use accessibilityLabel for all interactive elements

### Golf App Specifics
- Outdoor readability: High contrast required
- One-handed operation: Bottom-focused interactions
- Glanceable info: Large numbers, minimal text
- Weather context: Adapt to conditions display

### Iteration - 2026-01-14 (User Screenshot Fixes)
**Component:** Shot Calculator + Wind Calculator
**Phase:** critical-fixes
**Status:** COMPLETE

**User-Reported Issues from Screenshots (UIimages/):**

1. **PlaysLike Value Not Rendering** [FIXED]
   - Issue: Shot Calculator showed "yds" with no number
   - Root cause: `calculationResult.playsLike` was undefined before first calculation
   - Fix: Added fallback `String(calculationResult.playsLike || targetDistance)` in index.tsx
   - File: `app/(tabs-redesign)/index.tsx`

2. **Lock Button Overlapping S Cardinal** [FIXED]
   - Issue: Lock button positioned inside compass, overlapping S direction
   - Fix: Modified `getLockButtonMetrics` to position button BELOW compass
   - Used `bottom: -(buttonSize + 12)` for 12px gap below compass
   - Files: `src/utils/responsive.ts`, `src/features/wind/components/compass/styles.ts`

3. **Compass Visual Clutter** [FIXED]
   - Reduced DegreeMarks from 72 ticks (every 5°) to 8 ticks (every 45°)
   - Removed BlurView and LinearGradient - simplified to solid ring
   - Reduced pulse animation intensity (1.08→1.05, duration 1500→2000ms)
   - Cleaned up unused localStyles (compassGlow, gradientRing*, etc.)
   - Files: `DegreeMarks.tsx`, `WindDirectionCompass.tsx`

4. **Too Many Cardinal Presets** [FIXED]
   - Reduced from 8 presets (N, NE, E, SE, S, SW, W, NW) to 4 (N, E, S, W)
   - Redundant with compass functionality
   - File: `app/(tabs-redesign)/wind.tsx`

5. **Wind Screen Scrolling Issue** [FIXED]
   - Reordered layout: inputs FIRST → compass → forecast
   - New order: Target Distance → Quick Presets → Result Card → Compass → Wind Speed → Gust Warning → Forecast
   - Reduced scrolling required for common operations
   - File: `app/(tabs-redesign)/wind.tsx`

6. **Need Calculate Button** [FIXED]
   - Removed auto-update behavior (useMemo → useCallback)
   - Added explicit "Calculate" button with brand color
   - User must tap to calculate - no surprise recalculations
   - File: `app/(tabs-redesign)/index.tsx`

**TypeScript Check:** PASSED (npx tsc --noEmit --skipLibCheck)

**Next:** Look for additional UI polish opportunities
